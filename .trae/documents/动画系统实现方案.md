# 低代码编辑器「动画」功能实现方案

## Context（背景与目标）

当前编辑器顶部画布区有四个页签：视图 / 数据 / 事件 / 方法（`CenterTab`）。用户需要新增一套**动画**能力：

1. 顶部新增「动画」页签，展示动画卡片，可新增 / 编辑 / 删除动画。
2. 动画**独立于页面 / 组件文档**存储，落到 MongoDB 集合 `animation.version`（每个动画一条文档）。
3. 编辑动画弹窗（大弹窗）：上方左右分栏（左 50% 是可缩放/拖拽的三角形预览画布 + 坐标 + 还原/放大/缩小按钮；右 50% 是 8 个元素属性），下方是 0–100%（步进 0.1%）的关键帧时间轴 + 播放/暂停 + 播放选项（循环、往复）。
4. 选中控件后浮动工具栏新增「动画」按钮，展开配置：动画选择、时长、模式（默认单次，另有重复/往复/保持）、缓动（默认线性，另有 cubicIn 等）、清除。
5. 已确认：**包含运行时真实播放**；动画**每个一条文档**；控件**只存 animationId + 时长/模式/缓动**，运行时按 id 查动画目录。

属性语义（已与用户确认）：
- `translateX` / `translateY`：px；`rotateX` / `rotateY` / `rotateZ`：deg；`screw` = **skew**（deg）；`opacity`：0–1；`scale`：无单位倍数。

---

## 总体数据流

```
动画定义（独立资源）
  editor 动画面板 ──CRUD──▶ /projects/:id/animations ──▶ animation.version 集合
        │
        └─ 编辑器加载动画目录（catalog）→ 随 sendPreview 下发 → 运行时 installPageAnimations

控件绑定
  WidgetStyleBubble「动画」面板 ──▶ widget.animation = { id, duration, mode, easing }
        │（随页面 XML 一起持久化）
        └─ 运行时：pageCssText 依据 widget.animation + 动画目录，输出 @keyframes 与 animation 规则
```

### 1. 共享类型（`packages/shared/src/index.ts`）

新增（与 `NamespaceDocumentDto`、`RuntimeProjectDto` 同文件）：

```ts
export type AnimationProps = {
  translateX?: number; translateY?: number;
  rotateX?: number; rotateY?: number; rotateZ?: number;
  screw?: number;            // skew，单位 deg
  opacity?: number; scale?: number;
};
export type AnimationKeyframe = { offset: number /*0..100，步进0.1*/; props: AnimationProps };
export type AnimationDefinitionDto = { id: string; name: string; keyframes: AnimationKeyframe[]; updatedAt?: string };
export const ANIMATION_MODES = ['once', 'repeat', 'alternate', 'hold'] as const;   // 单次/重复/往复/保持
export type WidgetAnimationMode = (typeof ANIMATION_MODES)[number];
export const ANIMATION_EASINGS = ['linear','ease','easeIn','easeOut','easeInOut','cubicIn','cubicOut','cubicInOut'] as const;
export type WidgetAnimationEasing = (typeof ANIMATION_EASINGS)[number];
export type WidgetAnimationBinding = { id: string; duration: number /*ms*/; mode: WidgetAnimationMode; easing: WidgetAnimationEasing };
```

同时给 `RuntimeProjectDto` 增加可选的 `animations?: AnimationDefinitionDto[]`（发布页宿主可据此下发目录，与现有 `icons` 一致）。

## 验证

1. **构建 / 类型**：`pnpm build:packages`；`pnpm typecheck`。
2. **本地联调**：`pnpm dev`（或 `dev:editor` + `dev:editor-server`），打开工程编辑器。
3. **动画面板**：顶部出现「动画」页签 → 新增动画 → 卡片出现 → 编辑弹窗可缩放/拖拽三角形画布、还原/放大/缩小、坐标显示正确；拖动时间轴 0–100%（0.1 步进）打点、移动关键帧、播放/暂停与循环/往复选项生效。
4. **控件绑定**：选中控件 → 工具栏「动画」→ 选择动画/时长/模式/缓动 → 画布预览中控件按配置播放；清除后停止。
5. **持久化**：保存后刷新页面，动画定义与控件绑定均保留；`animation.version` 集合出现对应文档（后端直连或 mock 的 `animation.version/*.json`）。
6. **运行时**：编辑态预览与发布页（`GET /api/runtime/projects/:key/pages/:key` 配套）能获取动画目录并播放。
