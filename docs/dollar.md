# `$` 语法

页面脚本和绑定里，以 `$` 开头的名字是运行时提供的数据或方法。下面按用途列出。

## 数据

这些名字出现在页面数据的动态表达式、状态函数，以及文案绑定 `$(...)` 里。

| 写法 | 含义 |
| --- | --- |
| `$data` | 当前页的变量表 |
| `$data.名称` | 某个页面变量 |
| `$props` | 当前组件实例的入参 |
| `$props.名称` | 某个入参。控件双向绑定到入参时，`modelValue` 也写成这个形式 |
| `$query` | 当前页的查询参数 |
| `$query.名称` | 某个查询参数 |

页面数据表达式的形参就是 `$data`、`$props`、`$query`。未开启响应式时，数组和对象只在创建时求值一次，可以用 `$data.变量名` 读上方变量的初始值。开启响应式后，表达式会跟着 `$data` 和 `$props` 变化。

控件文案一类字段还有两种绑定：

- 路径：`$data.名称`、`$props.名称`、`$query.名称`。只取这一层值。
- 表达式：`$(表达式)`。表达式里可以写上面的名字，也可以写 `data` / `props` / `query`（和带 `$` 的是同一个对象）。

循环展开后，状态函数和 `$(...)` 里还能读到当前项：

| 写法 | 含义 |
| --- | --- |
| `$item` | 当前循环项。循环把「项」改成别的名字时，那个名字同样可用 |
| `$index` | 当前序号，从 0 开始。序号别名同理 |

## 文案

| 写法 | 含义 |
| --- | --- |
| `$t("分组.条目")` | 按当前语言取文案。分组和条目都不能带 `.` 或 `"` |

页面数据的 JSON 里也可以写这个调用，例如 `"label": $t("nav.home")`。保存后仍是调用本身，预览时按当前语言取值。输入 `$t("` 之后，编辑器会按语言库补全路径。

## 事件脚本里的方法

事件脚本在页面里执行，可以直接调用下面的全局方法。`$query` 在事件里同样是当前页的查询参数。

| 写法 | 含义 |
| --- | --- |
| `$toast(text, duration?)` | 弹出提示。`text` 是文案。`duration` 省略或 `0` 是短提示，`1` 是长提示 |
| `$navigateTo(pageKey, query?)` | 打开指定页面，并可带上查询参数。目标页用 `$query.参数名` 读取 |
| `$navigateBack(times?)` | 返回上一层。`times` 省略时为 1。数字更大就继续往前，停在本次打开时的首页 |
| `$icon('分组.名称')` | 按图标库路径取图标文件地址。见下一节 |
| `$emit(name, ...args)` | 触发当前组件的自定义事件。`name` 是事件名。后面的参数按顺序对应该事件的形参。输入 `$emit('` 之后，编辑器按已定义的事件补全名称，并提示对应形参 |
| `$data.名称(值)` | 写入这个页面变量。编译成 React 时是 `set名称(值)`，名称首字母大写 |
| `$props.名称(值)` | 写入这个入参。编译成 React 时同样是 `set名称(值)` |
| `$query.名称(值)` | 写入这个查询参数。编译成 React 时同样是 `set名称(值)` |

读取不加括号，例如 `$data.current`。写入才加括号，例如 `$props.current($item.key)` 会编译成 `setCurrent($item.key)`。循环展开后的事件里可以读 `$item` 和 `$index`。

## `$icon`

```js
$icon('nav.home')
```

参数是图标库里的 **分组.名称**，名称不含 `.svg`。返回这个图标的文件地址。库里没有这个路径时，原样返回传入的字符串。

页面数据、状态函数、`$(...)`、事件脚本，以及页面数据的 JSON 里都可以调用。JSON 里写成 `"icon": $icon('nav.home')`，保存后仍是这个调用。输入 `$icon('` 之后，编辑器会按已上传的图标补全路径。写完整句后，调用前面会显示这个图标。
