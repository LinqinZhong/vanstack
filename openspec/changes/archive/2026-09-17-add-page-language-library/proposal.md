## Why

工程编辑页已能写死文本/按钮文案，但缺少页面级多语言库与预览语言切换。作者需要集中维护分组文案、在控件里用 `$t("分组.键")` 引用，并让画布/运行时随当前语言切换文案与 LTR/RTL 排列方向。

## What Changes

- 工程编辑页顶栏按钮（返回首页、显示版本、保存）改为更小字号并带图标；在保存左侧新增「语言库」按钮。
- 点击语言库打开弹窗：上部管理语言（名称、键、排列方向 LTR/RTL），下部用 tab 管理分组；每个分组一张表，列为语言、行为文案键，支持新增语言、分组与键。
- 中间画布卡片标题栏右侧增加地球下拉框，用于选择当前预览语言。
- 文本/按钮的文案输入框允许填写 `$t("分组.键")`；输入框后增加地球按钮，弹出选择器写入该表达式。
- 页面 XML 增加页面级语言库；公共渲染按当前语言解析 `$t(...)`，并把页面 `dir` 设为该语言的 LTR 或 RTL。无语言库的既有页面仍合法，按字面文案与 LTR 渲染。
- 语言库编辑走当前草稿 XML，与撤回/重做、版本保存同一路径。不新增后端 API。

## Capabilities

### New Capabilities

- （无）

### Modified Capabilities

- `lowcode-runtime`: 页面 XML 识别语言库；工作台提供语言库弹窗、画布当前语言与文案选择器；公共渲染按当前语言解析 `$t("分组.键")` 并跟随排列方向。

## Impact

- **共享包**：`packages/xml` 解析/序列化页面级语言库；`packages/lowcode-runtime` 按 locale 解析 `$t` 并设置页面方向。
- **前端**：`apps/frontend-admin` 顶栏按钮样式、语言库弹窗、画布地球下拉、文案输入地球选择器、预览协议携带当前语言；`apps/frontend-app` 按页面语言库选择运行时语言。
- **后端 / API**：无。语言库随版本 XML 写入 OSS。
- **兼容**：无语言库、无 `$t(...)` 的既有页面仍按字面文案与 LTR 渲染。
- **非目标**：工程级共享语言库、ICU/复数插值、逻辑 CSS 边距自动镜像、管理后台工作台自身 zh/en 与页面语言库混用。
