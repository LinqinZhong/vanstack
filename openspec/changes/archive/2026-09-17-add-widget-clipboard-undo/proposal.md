## Why

工作台已能添加、选中并改属性，但选中控件后无法删除、复制、粘贴，也无法撤回或重做误操作。编辑嵌套树时这些操作是基本编辑循环，缺少它们会迫使管理员用新建或重新加载版本来纠错。

## What Changes

- 工作台在编辑草稿版本时，对当前选中控件提供删除、复制、粘贴；粘贴插入一份带新 `id` 的子树副本，预览即时反映。
- 工作台为控件树变更提供会话内撤回与重做：添加、删除、粘贴、属性编辑均可逐步还原；新操作会清空重做栈。
- 上述操作同时提供按钮入口与快捷键（删除、复制、粘贴、撤回、重做）；焦点在输入框内或处于预览/已发布只读态时 MUST NOT 误触发。
- 预览 iframe 在编辑态把快捷键转发给主窗口，保证点选画布后快捷键仍可用。
- 不改页面 XML schema、后端 API、H5 运行时与公共渲染器。

## Capabilities

### New Capabilities

- 无。删除/剪贴板/历史是现有工作台编辑契约的扩展，不单独成能力。

### Modified Capabilities

- `lowcode-runtime`: 工作台支持删除、复制、粘贴当前控件（含子树），以及控件树变更的撤回/重做；按钮与快捷键在编辑草稿时可用，只读态禁用；预览随变更即时更新。

## Impact

- `frontend-admin`：`widgetTree` 增加删除/插入/克隆 helper；工作台增加剪贴板、历史栈、快捷键监听与控件树工具栏按钮；预览协议增加 iframe 键盘转发。
- `frontend-admin` 中英 i18n 覆盖删除、复制、粘贴、撤回、重做标签。
- `@vanstack/xml`、`@vanstack/lowcode-runtime`、后端页面/版本 API 与 H5 不变；粘贴只改当前会话中的控件树，保存版本后才持久化。
- 非目标：剪切、多选、系统剪贴板、跨页面/跨工程粘贴、页面/版本 CRUD 与画布平移缩放的撤回、历史跨刷新持久化。
