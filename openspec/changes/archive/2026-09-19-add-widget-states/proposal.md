## Why

工作台目前每个控件只有一套外观属性。作者无法为同一控件树准备多种视觉状态（例如默认与激活），只能复制整棵子树或靠预览时硬改 XML。需要在画布上直接管理状态，并把差异写进页面 XML，编辑时切换状态改属性，预览与 H5 按选用状态渲染。

## What Changes

- 每个可选中控件 SHALL 始终具有隐式 `initial` 状态（控件自身属性）。作者可在状态树中为当前选中控件创建命名自定义状态或继承态下的子状态。
- 自定义状态在 XML 中用控件内的 `<_ name="...">` 子元素表示；继承覆盖用 `<__>`；子状态 MUST 写在对应 `<__>` 内部的 `<_>`。
- 选中控件的状态树 MUST 以 `initial` 开头，继承态为可折叠非叶子。后代若对某祖先状态有自己的属性差异或子状态，MUST 用 `<__ name="...">` 写出。
- 控件可设「选用状态」：XML 属性 `state="name"`；缺省 MUST 为 `initial`。只有拥有该状态的控件才能选用。预览模式与 H5 运行 MUST 使用选用状态；编辑模式画布、气泡与检查器 MUST 使用状态树中当前查看的状态。
- 若某控件拥有名为 `hover` 的状态，预览与 H5 在鼠标悬停该控件时 MUST 自动命中 `hover`（临时覆盖该控件的选用）；离开后回落选用。编辑模式 MUST NOT 自动命中。
- 画布网格左侧 MUST 显示可折叠状态树：拥有态白色、继承态灰白色；只有叶子可编辑删除、打勾；添加在右键菜单与列表底部。选中不同状态后画布立即按该状态的解析属性显示，便于编辑。

## Capabilities

### New Capabilities

- （无）

### Modified Capabilities

- `lowcode-runtime`: 页面 XML 增加控件状态声明、继承与选用；工作台画布提供状态列表；编辑按选中状态读写属性，预览与 H5 按选用状态渲染。

## Impact

- `@vanstack/xml`：`PageWidget` 增加状态字段；解析/序列化 `<_>` / `<__>` / `state`；提供默认与命名状态的属性合并与差异压缩。既有无状态 XML 仍合法。
- `@vanstack/lowcode-runtime`：渲染前按选用或编辑态覆盖状态合并样式后再画。管理后台 iframe 与 H5 共用。
- `frontend-admin`：画布状态列表、选中状态驱动属性编辑、预览消息携带编辑态覆盖、气泡/检查器/画布手势写入当前状态的差异。中英 i18n。
- 非目标：页面根级状态、按状态分叉子树或文案、状态动画/过渡、事件里切换状态、多选控件批量改状态。
