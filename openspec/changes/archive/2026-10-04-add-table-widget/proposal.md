## Why

工作台能编排文本、按钮、弹性盒和滑动器，但没有表格，无法表达表头、行列和单元格样式。需要新增表格控件：编辑时整张表都看得见、不能在表内滚动，预览时再按溢出策略决定是否滚动。

## What Changes

- 页面 XML 新增 `table`，直接子元素为表头单元格 `th` 与数据行 `tr`，`tr` 的直接子元素为 `td`。列数等于 `th` 个数，每个 `td` 按顺序对齐到对应列。
- `th` 与 `td` 是带 `value` 文案的叶子单元格，不接受子控件。列宽写在 `th` 上，数据行行高写在 `tr` 上，表头行高写在 `table` 上。
- `table` 可设置表头冻结与溢出策略（沿用 `visible` / `hidden` / `scroll` / `auto`）。编辑态忽略溢出策略，整张表按列宽行高铺开，溢出可见且表内不出现滚动条。预览与 H5 按溢出策略裁剪或滚动；仅在预览滚动时，表头冻结才把表头行吸在滚动口顶部。
- 选中表格内部时，气泡工具栏提供「结构」与「布局」两种编辑铬模式（不写入 XML）。结构模式可添加、删除、移动列与数据行。布局模式可用数字或拖拽设置列宽与行高。
- 编辑态可选中整列、整行或单个单元格。选中列或行时，单元格样式应用到该范围的全部单元格；选中单个单元格时只改该格。样式包括背景、边框、文本样式与水平/垂直对齐。
- 新表格默认 3 列、1 行表头、3 行数据。`table` 可放在页面根、弹性盒或滑动器页内；`th` / `tr` / `td` 不能单独放到这些位置，也不出现在添加弹窗里。
- 已有不含 `table` 的页面 XML 仍合法。`PageWidget` 扩展后，穷尽匹配控件类型的调用方必须处理 `table`、`th`、`tr` 与 `td`。

## Capabilities

### New Capabilities

- 无。表格是现有页面控件契约的扩展，不单独成能力。

### Modified Capabilities

- `lowcode-runtime`: 页面 XML 识别并渲染 `table` / `th` / `tr` / `td`；工作台支持结构模式改行列、布局模式改列宽行高、选中列/行以及单元格样式；编辑态整表可见且不滚动，预览与 H5 按溢出策略滚动，并支持表头冻结。

## Impact

- `@vanstack/xml`：`PageWidget` 增加 `table`、`th`、`tr`、`td`；解析与序列化表头冻结、溢出、列宽、行高、单元格文案与样式。
- `@vanstack/lowcode-runtime`：同一份 DOM 在编辑态铺开整表，在预览与 H5 按溢出策略形成滚动口，并在需要时冻结表头。
- `frontend-admin`：添加表格、控件树、气泡上的结构/布局模式、列行选中、列宽行高拖拽、单元格样式；`th` / `tr` / `td` 不进添加弹窗。
- `frontend-app`：随公共渲染获得预览行为，不出现编辑铬。
- 后端页面/版本 API 与 OSS 存储不变。
- 中英 i18n 覆盖表格、表头、行、单元格、结构模式、布局模式、表头冻结与对齐文案。
